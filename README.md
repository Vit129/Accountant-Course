## ฟีเจอร์อื่นๆ

- **Sequential lock** — บทถัดไปล็อคจนกว่าจะทำบทก่อนหน้าผ่าน เปิดหน้าใหม่จะ resume ไปบทแรกที่ยังไม่ผ่านอัตโนมัติ
- **Daily check-in** — นับวันเข้าเรียนต่อเนื่อง (ต้องทำโจทย์ผ่านอย่างน้อย 1 บทต่อวันถึงนับ)
- **Gamification** — milestone popup (50%/75%) และใบประกาศจบวิชาเมื่อผ่านครบ 100%
- **Export/Import ความคืบหน้า** — สำรอง/กู้คืนความคืบหน้าทั้งหมดเป็นไฟล์ JSON
- **Self-test suite** (`npm test`) — ตรวจสอบอัตโนมัติว่าทุกบทเรียนมี solution ที่ผ่านและ template ที่ยังไม่ผ่าน ป้องกัน regex เพี้ยนแบบเงียบๆ

## ข้อจำกัด (ตรงไปตรงมา)

ข้อสอบจำลองในเว็บนี้ (รวมถึงบทที่ระบุ "แนวข้อสอบ CPA (จำลอง)") เป็น**ตัวแทนหัวข้อที่แต่งขึ้นเอง** ไม่ใช่ข้อสอบเก่าจากสภาวิชาชีพบัญชี (ไม่มีแหล่งข้อสอบจริงย้อนหลังเผยแพร่แบบเปิดเผยให้ดึงมาใช้) และไม่ครอบคลุมมาตรฐาน/มาตรากฎหมายทั้งหมด ใช้ซ้อมความเข้าใจได้ แต่ควรหา past papers จริงมาฝึกเพิ่มก่อนสอบจริง

## เทคโนโลยี

Static site — HTML, CSS, Vanilla JS ล้วน ไม่มี build step ทดสอบแล้วบน Chrome เปิด `index.html` ได้ตรงๆ (browser อื่นบางตัวอาจบล็อค script ข้ามโฟลเดอร์เมื่อเปิดผ่าน `file://` — ถ้าไม่ขึ้นเนื้อหา ให้ clone แล้วเปิดผ่าน local server แทน)
