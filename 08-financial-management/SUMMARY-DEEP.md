## 1. มูลค่าเงินตามเวลา (Time Value of Money)

*อ้างอิงบทเรียน: `fv-lump-sum`, `pv-lump-sum`, `pv-annuity` (บทที่ 1)*

### 1.1 หลักการและสูตรหลัก

| แนวคิด | สูตร |
|---|---|
| มูลค่าในอนาคตของเงินก้อนเดียว | `FV = PV × (1+r)^n` |
| มูลค่าปัจจุบันของเงินก้อนเดียว | `PV = FV ÷ (1+r)^n` |
| มูลค่าปัจจุบันของเงินรับรายงวดปกติ (Ordinary Annuity) | `PV = PMT × [1-(1+r)^-n] ÷ r` |
| มูลค่าในอนาคตของเงินรับรายงวดปกติ | `FV = PMT × [(1+r)^n - 1] ÷ r` |
| เงินรับรายงวดต้นงวด (Annuity Due) | `PV(Due) = PV(Ordinary) × (1+r)` |
| เงินรับตลอดไป (Perpetuity) | `PV = PMT ÷ r` |
| เงินรับตลอดไปแบบเติบโต (Growing Perpetuity) | `PV = D1 ÷ (r-g)` (สูตรเดียวกับ Gordon Growth Model — ดูบทที่ 4) |
| เงินรับรายงวดแบบเติบโต (Growing Annuity) | `PV = PMT/(r-g) × [1-((1+g)/(1+r))^n]` |

**หลักการทบต้นแบบไม่ใช่รายปี (Non-Annual Compounding):** เมื่อโจทย์ให้ "อัตราดอกเบี้ยตามที่ระบุ (Nominal/Stated Rate)" แต่ทบต้นบ่อยกว่าปีละครั้ง (รายเดือน รายไตรมาส รายครึ่งปี) **ต้องแปลง r และ n ให้เป็นหน่วยเดียวกับความถี่การทบต้นก่อนเสมอ**:
- r ต่องวด = อัตรารายปีที่ระบุ ÷ จำนวนงวดต่อปี (m)
- n ต่องวด = จำนวนปี × จำนวนงวดต่อปี (m)

### 1.2 ตัวอย่างตัวเลขซับซ้อน

**ตัวอย่าง A — ทบต้นรายไตรมาส:** ฝากเงิน 200,000 บาท อัตราดอกเบี้ยระบุ 12% ต่อปี ทบต้นทุกไตรมาส เป็นเวลา 3 ปี
- r ต่อไตรมาส = 12% ÷ 4 = 3%, n = 3×4 = 12 งวด
- FV = 200,000 × (1.03)^12 = 200,000 × 1.42576 ≈ **285,152 บาท**
- (เทียบกับทบต้นรายปีธรรมดา 12%: FV = 200,000×(1.12)^3 = 280,986 → ยิ่งทบต้นถี่ FV ยิ่งสูงขึ้น)

**ตัวอย่าง B — PV ของกระแสเงินสดไม่เท่ากัน (Uneven Cash Flow):** จะได้รับเงิน 40,000 / 60,000 / 80,000 บาท ในปีที่ 1, 2, 3 ตามลำดับ อัตราคิดลด 9%
- PV1 = 40,000 ÷ 1.09 = 36,697
- PV2 = 60,000 ÷ 1.09² = 50,501
- PV3 = 80,000 ÷ 1.09³ = 61,774
- รวม PV ≈ **148,972 บาท** (ต้องคิดลดทีละปี ห้ามรวมกระแสเงินสดก่อนแล้วคิดลดครั้งเดียว)

### 1.3 จุดที่ข้อสอบชอบออก / กับดัก

- **ลืมแปลงหน่วยเมื่อทบต้นไม่ใช่รายปี** — ใช้ r รายปีตรง ๆ คูณกับ n เป็นปี ทั้งที่โจทย์บอกทบต้นรายเดือน/ไตรมาส เป็นกับดักที่พบบ่อยที่สุดในหมวดนี้
- **Ordinary Annuity vs Annuity Due** — โจทย์ระบุ "รับเงินต้นงวด" (เช่น ค่าเช่าที่จ่ายล่วงหน้า) ต้องคูณผลลัพธ์ปกติด้วย (1+r) อีกครั้ง มิฉะนั้นคำตอบจะต่ำกว่าความเป็นจริง
- **PV ของกระแสเงินสดไม่เท่ากัน** ห้ามใช้ตัวประกอบ PVIFA (ซึ่งใช้ได้เฉพาะกระแสเงินสด "เท่ากันทุกงวด") ต้องคิดลดทีละปีแยกกัน

## 2. การประเมินโครงการลงทุน (Capital Budgeting)

*อ้างอิงบทเรียน: `npv`, `payback-period` (บทที่ 2), `ocf-tax-shield`, `irr-interpolation` (แนวข้อสอบ · บทที่ 2), `terminal-cash-flow` (แนวข้อสอบ · บทที่ 10)*

### 2.1 ลำดับการคำนวณกระแสเงินสดโครงการที่ถูกต้อง

ข้อสอบ CPA มักให้ข้อมูลดิบ (ยอดขาย ต้นทุน ค่าเสื่อมราคา) แล้วให้คำนวณกระแสเงินสดเอง **ห้ามใช้ยอดขายลบต้นทุนตรง ๆ**:

1. **EBT** = ยอดขาย − ต้นทุนดำเนินงานที่เป็นเงินสด − ค่าเสื่อมราคา
2. **ภาษี** = EBT × อัตราภาษี ; **กำไรสุทธิ (NI)** = EBT − ภาษี
3. **OCF (Operating Cash Flow)** = NI + ค่าเสื่อมราคา (บวกกลับเพราะไม่ใช่เงินสดจ่ายจริง)
   - สูตรลัด: `OCF = (ยอดขาย - ต้นทุนดำเนินงาน) × (1-T) + ค่าเสื่อมราคา × T`
4. **Terminal Cash Flow** (ปีสุดท้ายเท่านั้น) = มูลค่าซากหลังภาษี + เงินทุนหมุนเวียนที่ได้รับคืน
   - มูลค่าซากหลังภาษี = ราคาขาย(ซาก) − [(ราคาขาย(ซาก) − มูลค่าตามบัญชี Book Value) × อัตราภาษี]
   - Book Value = ราคาทุน − ค่าเสื่อมราคาสะสม
5. **NPV** = Σ PV(กระแสเงินสดสุทธิแต่ละปี) − เงินลงทุนเริ่มแรก

### 2.2 เกณฑ์การประเมินโครงการ

| เครื่องมือ | สูตร | เกณฑ์ตัดสินใจ |
|---|---|---|
| NPV | Σ PV(CF) − Investment | รับถ้า NPV > 0 |
| IRR | อัตราคิดลดที่ทำให้ NPV = 0 | รับถ้า IRR > WACC |
| Payback Period | เงินลงทุนเริ่มแรก ÷ กระแสเงินสด/ปี (กรณีเท่ากันทุกปี) | สั้นกว่าเกณฑ์ที่กำหนด |
| Discounted Payback | ใช้ PV ของกระแสเงินสดแทนกระแสเงินสดดิบ | สั้นกว่าเกณฑ์ที่กำหนด |
| Profitability Index (PI) | Σ PV(CF) ÷ Investment | รับถ้า PI > 1 (เทียบเท่า NPV>0) |
| MIRR | อัตราคิดลดที่ทำให้ PV(ต้นทุน) = PV(FV ของกระแสเงินสดรับที่ทบต้นด้วย WACC ณ ปีสุดท้าย) | รับถ้า MIRR > WACC |

### 2.3 การประมาณ IRR ด้วยวิธี Interpolation (เมื่อไม่มีเครื่องคิดเลขการเงิน)

1. คำนวณ NPV ที่อัตราคิดลดต่ำ (r1) ให้ได้ค่า **บวก**
2. คำนวณ NPV ที่อัตราคิดลดสูง (r2) ให้ได้ค่า **ลบ**
3. `IRR ≈ r1 + [NPV1 ÷ (NPV1 - NPV2)] × (r2 - r1)`

**ตัวอย่างซับซ้อน (โครงการกระแสเงินสดไม่เท่ากัน):** ลงทุน 300,000 บาท ได้รับกระแสเงินสด ปีที่ 1–3 = 100,000 / 130,000 / 160,000 บาท
- ที่ r=12%: PV = 100,000/1.12 + 130,000/1.2544 + 160,000/1.404928 = 89,286 + 103,635 + 113,884 = 306,805 → NPV₁ = +6,805
- ที่ r=15%: PV = 100,000/1.15 + 130,000/1.3225 + 160,000/1.520875 = 86,957 + 98,299 + 105,204 = 290,460 → NPV₂ = −9,540
- IRR ≈ 12% + [6,805 ÷ (6,805+9,540)] × (15%-12%) ≈ 12% + (0.4165×3%) ≈ **13.25%**

### 2.4 จุดที่ข้อสอบชอบออก / กับดัก

- **OCF ต้องผ่าน EBT เสมอ** — ข้อสอบชอบตั้งให้นักศึกษาลืมหักภาษีก่อนบวกค่าเสื่อมราคากลับ (เอา "ยอดขาย−ต้นทุน−ค่าเสื่อม" มาบวกค่าเสื่อมกลับตรง ๆ โดยไม่คิดภาษี = ผิด)
- **มูลค่าซากหลังภาษี** ต้องเทียบกับ **Book Value ไม่ใช่ราคาทุนเดิม** — ถ้าราคาขายสูงกว่า Book Value เกิดกำไรต้องเสียภาษี ถ้าต่ำกว่าเกิดขาดทุนได้รับผลประโยชน์ทางภาษี (ลดภาษี)
- **NPV vs IRR Conflict** — เมื่อเปรียบเทียบโครงการที่แข่งขันกัน (Mutually Exclusive) ที่มีขนาดเงินลงทุนหรือรูปแบบกระแสเงินสดต่างกันมาก IRR อาจให้อันดับขัดแย้งกับ NPV ได้ **ให้ยึด NPV เป็นเกณฑ์หลักเสมอ** เพราะสะท้อนมูลค่าเพิ่มเป็นตัวเงินจริง ไม่ใช่อัตราร้อยละ
- **Multiple IRR** — หากกระแสเงินสดของโครงการเปลี่ยนเครื่องหมาย (ลบ→บวก→ลบ) มากกว่า 1 ครั้ง (เช่น มีค่าใช้จ่ายรื้อถอนก้อนใหญ่ปีสุดท้าย) อาจมี IRR ได้หลายค่า ทำให้เกณฑ์ IRR ใช้ไม่ได้ ต้องใช้ NPV แทน
- **เงินทุนหมุนเวียนเริ่มโครงการ** ถือเป็นเงินลงทุนเพิ่มเติม ณ ปีที่ 0 และ**ได้รับคืนเต็มจำนวน**ในปีสุดท้าย (ไม่มีผลกระทบทางภาษี ต่างจากมูลค่าซากสินทรัพย์ถาวร)

## 3. ต้นทุนเงินทุน (Cost of Capital)

*อ้างอิงบทเรียน: `wacc`, `cost-of-debt` (บทที่ 3), `capm-cost-of-equity` (แนวข้อสอบ · บทที่ 3), `wacc-preferred-flotation` (แนวข้อสอบ · บทที่ 9)*

### 3.1 ต้นทุนแต่ละองค์ประกอบ

| แหล่งเงินทุน | สูตร |
|---|---|
| ต้นทุนหนี้สินหลังภาษี (Rd) | `Rd × (1-T)` |
| ต้นทุนส่วนของผู้ถือหุ้นสามัญ — CAPM | `Re = Rf + β × (Rm - Rf)` |
| ต้นทุนส่วนของผู้ถือหุ้นสามัญ — Gordon Growth | `Re = D1/P0 + g` |
| ต้นทุนส่วนของผู้ถือหุ้นสามัญ — ออกหุ้นใหม่ (มี Flotation Cost) | `Re = D1/[P0×(1-F)] + g` |
| ต้นทุนหุ้นบุริมสิทธิ (Rps) | `Rps = เงินปันผลบุริมสิทธิ ÷ ราคาขายสุทธิ` (ราคาขายสุทธิ = ราคาขาย − Flotation Cost) |

### 3.2 WACC

- **2 องค์ประกอบ**: `WACC = (Wd×Rd หลังภาษี) + (We×Re)`
- **3 องค์ประกอบ (มีหุ้นบุริมสิทธิ)**: `WACC = (Wd×Rd) + (Wps×Rps) + (We×Re)` — น้ำหนักทั้งหมดรวมกันต้องเท่ากับ 100%

### 3.3 ตัวอย่างซับซ้อน — ต้นทุนหุ้นสามัญออกใหม่ + Break Point ของ Marginal Cost of Capital

**ต้นทุนหุ้นสามัญออกใหม่ (New Common Stock with Flotation Cost):** บริษัทคาดว่าจะจ่ายเงินปันผลปีหน้า (D1) 5 บาท/หุ้น ราคาตลาดปัจจุบัน 50 บาท ต้นทุนการออกหุ้นใหม่ (Flotation Cost) 10% ของราคาขาย อัตราเติบโต 6%
- ราคาขายสุทธิ = 50 × (1-0.10) = 45
- Re(หุ้นใหม่) = 5÷45 + 6% = 11.11% + 6% = **17.11%** (สูงกว่าต้นทุนกำไรสะสม (Retained Earnings) ที่ไม่มี Flotation Cost = 5÷50+6% = 16%)

**จุดหักเห (Break Point) ของ Marginal Cost of Capital:** เมื่อกำไรสะสมที่มีอยู่ (Retained Earnings) หมดลง กิจการต้องออกหุ้นใหม่ที่มีต้นทุนสูงกว่า จุดที่เงินทุนรวมทำให้กำไรสะสมหมดพอดี คือ:
`Break Point = กำไรสะสมที่มีอยู่ ÷ สัดส่วนส่วนของผู้ถือหุ้นในโครงสร้างเงินทุน (We)`
ตัวอย่าง: กำไรสะสมคงเหลือ 300,000 บาท, We = 60% → Break Point = 300,000 ÷ 0.60 = **500,000 บาท** (เมื่อระดมทุนรวมเกิน 500,000 บาท WACC จะปรับสูงขึ้นเพราะต้องใช้ต้นทุนหุ้นใหม่)

### 3.4 จุดที่ข้อสอบชอบออก / กับดัก

- **CAPM: Market Risk Premium ให้มา 2 แบบ** — (1) ให้ Rm ตรง ๆ ต้องคำนวณ (Rm−Rf) เอง หรือ (2) ให้ "ส่วนชดเชยความเสี่ยงตลาด (Market Risk Premium)" มาโดยตรง = (Rm−Rf) พร้อมใช้แล้ว **ห้ามนำไปลบ Rf ซ้ำอีกครั้ง** — นี่คือกับดักที่ข้อสอบใช้ทดสอบบ่อยที่สุดในหมวด CAPM
- **ต้นทุนหุ้นบุริมสิทธิต้องใช้ราคาขายสุทธิ** (หลังหัก Flotation Cost) ไม่ใช่ราคาขายเต็มจำนวน เพราะเงินสดที่กิจการได้รับจริงมีเพียงราคาสุทธิ
- **WACC ต้องใช้ Rd หลังภาษีเสมอ** ไม่ใช่ Rd ก่อนภาษีที่ระบุในสัญญาเงินกู้
- **สัดส่วนน้ำหนัก (Wd, Wps, We)** ควรใช้ "มูลค่าตามราคาตลาด (Market Value)" ของแหล่งเงินทุนแต่ละประเภท ไม่ใช่มูลค่าตามบัญชี หากโจทย์ให้มูลค่าตลาดมาต้องใช้มูลค่าตลาด

## 4. การประเมินมูลค่าหลักทรัพย์ (Securities Valuation)

*อ้างอิงบทเรียน: `dividend-discount-model` (บทที่ 4), `bond-valuation` (บทที่ 8), `bond-valuation-semiannual` (แนวข้อสอบ · บทที่ 13)*

### 4.1 การประเมินมูลค่าหุ้นสามัญ (Dividend Discount Model)

| กรณี | สูตร |
|---|---|
| เงินปันผลคงที่ตลอดไป (Zero Growth — ใช้กับหุ้นบุริมสิทธิด้วย) | `P0 = D ÷ r` |
| เงินปันผลเติบโตคงที่ (Constant/Gordon Growth) | `P0 = D1 ÷ (r-g)` (สมมติ g < r เสมอ) |
| เติบโตสองช่วง (Two-Stage/Supernormal Growth) | คิดลด D แต่ละปีในช่วงเติบโตสูงแยกกัน + คิดลดราคาขายปลายช่วง (ใช้ Gordon Growth ที่จุดเริ่มเติบโตคงที่) กลับมาเป็น PV รวมกัน |

**ตัวอย่างซับซ้อน — Two-Stage DDM:** บริษัทเพิ่งจ่ายเงินปันผล D0 = 2 บาท/หุ้น คาดว่าจะเติบโต 20% ต่อปีใน 2 ปีแรก จากนั้นเติบโตคงที่ 5% ต่อไป ผู้ถือหุ้นต้องการผลตอบแทน 12%
- D1 = 2×1.20 = 2.40 ; D2 = 2.40×1.20 = 2.88 ; D3 = 2.88×1.05 = 3.024
- P2 (ราคา ณ สิ้นปีที่ 2 โดยใช้ Gordon Growth) = D3 ÷ (r-g) = 3.024 ÷ (0.12-0.05) = 3.024÷0.07 = 43.20
- PV(D1) = 2.40÷1.12 = 2.14 ; PV(D2) = 2.88÷1.12² = 2.30 ; PV(P2) = 43.20÷1.12² = 34.44
- P0 = 2.14+2.30+34.44 ≈ **38.88 บาท/หุ้น**

### 4.2 การประเมินมูลค่าพันธบัตร (Bond Valuation)

`มูลค่าพันธบัตร = (ดอกเบี้ยต่องวด × PVIFA(r,n)) + (มูลค่าที่ตราไว้ × PVIF(r,n))`

**พันธบัตรจ่ายดอกเบี้ยปีละ 2 ครั้ง (Semi-Annual) — ต้องแปลงหน่วยก่อนเสมอ:**
1. ดอกเบี้ยต่องวด = มูลค่าที่ตราไว้ × อัตราหน้าตั๋วรายปี ÷ 2
2. จำนวนงวด = จำนวนปี × 2
3. อัตราต่องวด = YTM รายปี ÷ 2

**ความสัมพันธ์ Par/Premium/Discount:**
- อัตราหน้าตั๋ว (Coupon Rate) = อัตราตลาด (YTM) → ราคา = มูลค่าที่ตราไว้ (Par)
- อัตราตลาด > อัตราหน้าตั๋ว → ราคา < มูลค่าที่ตราไว้ (Discount Bond)
- อัตราตลาด < อัตราหน้าตั๋ว → ราคา > มูลค่าที่ตราไว้ (Premium Bond)

**การประมาณ YTM แบบลัด (Approximate Yield to Maturity):**
`YTM ≈ [ดอกเบี้ยต่อปี + (มูลค่าที่ตราไว้ - ราคาตลาด)/n] ÷ [(มูลค่าที่ตราไว้ + ราคาตลาด)/2]`

ตัวอย่าง: พันธบัตรราคาตลาด 950 บาท มูลค่าที่ตราไว้ 1,000 บาท ดอกเบี้ย 80 บาท/ปี อายุคงเหลือ 5 ปี
`YTM ≈ [80 + (1,000-950)/5] ÷ [(1,000+950)/2] = [80+10] ÷ 975 = 90÷975 ≈ 9.23%`

### 4.3 จุดที่ข้อสอบชอบออก / กับดัก

- **ลืมแปลง n และ r เป็นหน่วยครึ่งปี** เมื่อพันธบัตรจ่ายดอกเบี้ยปีละ 2 ครั้ง — เป็นข้อผิดพลาดที่พบบ่อยที่สุดในหมวดพันธบัตร ทำให้ตัวประกอบ PVIFA/PVIF ที่ใช้ผิดไปทั้งหมด
- **Two-Stage DDM**: มูลค่า P (ราคาปลายช่วงเติบโตสูง) ที่คำนวณจาก Gordon Growth คือราคา ณ **สิ้นปีที่เริ่มเติบโตคงที่ลบ 1 ปี** (เช่น ถ้าเติบโตคงที่เริ่มปีที่ 3 ให้คิด P2 ไม่ใช่ P3) นักศึกษามักคิดปีผิด
- **หุ้นบุริมสิทธิ = Zero Growth Perpetuity** (P0 = D÷r) มักถูกเข้าใจผิดว่าต้องใช้ Gordon Growth Model เสมอ ทั้งที่หุ้นบุริมสิทธิจ่ายเงินปันผลคงที่ ไม่มีการเติบโต (g=0)

## 5. อัตราส่วนทางการเงินและ DuPont Analysis

*อ้างอิงบทเรียน: `current-ratio`, `debt-to-equity`, `roe-dupont` (บทที่ 5), `dupont-3-step` (แนวข้อสอบ · บทที่ 5)*

### 5.1 กลุ่มอัตราส่วนหลัก

| กลุ่ม | อัตราส่วน | สูตร |
|---|---|---|
| สภาพคล่อง (Liquidity) | Current Ratio | สินทรัพย์หมุนเวียน ÷ หนี้สินหมุนเวียน |
| สภาพคล่อง | Quick Ratio (Acid-Test) | (สินทรัพย์หมุนเวียน − สินค้าคงเหลือ) ÷ หนี้สินหมุนเวียน |
| โครงสร้างเงินทุน (Leverage) | Debt-to-Equity | หนี้สินรวม ÷ ส่วนของเจ้าของ |
| โครงสร้างเงินทุน | Times Interest Earned (TIE) | EBIT ÷ ดอกเบี้ยจ่าย |
| ความสามารถทำกำไร | ROE | กำไรสุทธิ ÷ ส่วนของเจ้าของ |
| ความสามารถทำกำไร | ROA | กำไรสุทธิ ÷ สินทรัพย์รวม |
| ประสิทธิภาพ | Asset Turnover | ยอดขาย ÷ สินทรัพย์รวม |

### 5.2 DuPont Analysis — 3 ขั้นตอน และแบบขยาย 5 ขั้นตอน

**DuPont 3 ขั้นตอน (มาตรฐาน):**
`ROE = Net Profit Margin × Asset Turnover × Equity Multiplier`
- Net Profit Margin = กำไรสุทธิ ÷ ยอดขาย (สะท้อนความสามารถทำกำไร)
- Asset Turnover = ยอดขาย ÷ สินทรัพย์รวม (สะท้อนประสิทธิภาพใช้สินทรัพย์)
- Equity Multiplier = สินทรัพย์รวม ÷ ส่วนของเจ้าของ (สะท้อนการใช้หนี้สิน/Financial Leverage)

**DuPont 5 ขั้นตอน (ขยาย — แยกผลกระทบภาษีและดอกเบี้ยออกจากกัน):**
`ROE = (NI÷EBT) × (EBT÷EBIT) × (EBIT÷ยอดขาย) × (ยอดขาย÷สินทรัพย์รวม) × (สินทรัพย์รวม÷ส่วนของเจ้าของ)`
= Tax Burden × Interest Burden × Operating Margin × Asset Turnover × Equity Multiplier

**ตัวอย่างซับซ้อน (DuPont 5 ขั้นตอน):** ยอดขาย 2,000,000 บาท EBIT 300,000 บาท ดอกเบี้ยจ่าย 60,000 บาท (EBT = 240,000) อัตราภาษี 25% (NI = 180,000) สินทรัพย์รวม 1,500,000 บาท ส่วนของเจ้าของ 750,000 บาท
- Tax Burden = NI÷EBT = 180,000÷240,000 = 0.75
- Interest Burden = EBT÷EBIT = 240,000÷300,000 = 0.80
- Operating Margin = EBIT÷ยอดขาย = 300,000÷2,000,000 = 0.15
- Asset Turnover = 2,000,000÷1,500,000 = 1.333
- Equity Multiplier = 1,500,000÷750,000 = 2.00
- ROE = 0.75×0.80×0.15×1.333×2.00 = **0.24 = 24%** (ตรวจสอบ: NI÷Equity = 180,000÷750,000 = 24% ✓)

### 5.3 จุดที่ข้อสอบชอบออก / กับดัก

- **ROE สูงไม่ได้แปลว่าดีเสมอ** — ต้องแยกด้วย DuPont ว่ามาจากความสามารถทำกำไรที่แท้จริง (ยั่งยืน) หรือมาจาก Equity Multiplier สูง (ก่อหนี้มาก = เสี่ยงสูง) ข้อสอบชอบให้เปรียบเทียบ 2 บริษัทที่ ROE เท่ากันแต่โครงสร้างต่างกัน แล้วถามว่าบริษัทใดมีความเสี่ยงทางการเงินสูงกว่า
- **Quick Ratio ตัดสินค้าคงเหลือออก** เพราะสินค้าคงเหลือแปลงเป็นเงินสดได้ช้าและไม่แน่นอนที่สุดในบรรดาสินทรัพย์หมุนเวียน — โจทย์ที่ให้ Current Ratio สูงแต่ Quick Ratio ต่ำมาก บ่งชี้ว่ากิจการมีสินค้าคงเหลือค้างสต็อกจำนวนมาก
- **DuPont 3 ขั้นตอน vs 5 ขั้นตอน**: 3 ขั้นตอนใช้ Net Profit Margin ตัวเดียวรวมผลกระทบภาษีและดอกเบี้ยไว้ด้วยกัน ส่วน 5 ขั้นตอนแยกทั้งสองออกจากกัน ให้อ่านโจทย์ว่าต้องการวิเคราะห์ระดับใด

## 6. การบริหารเงินทุนหมุนเวียน (Working Capital Management)

*อ้างอิงบทเรียน: `net-working-capital` (บทที่ 6), `cash-conversion-cycle` (แนวข้อสอบ · บทที่ 6)*

### 6.1 เงินทุนหมุนเวียนสุทธิ และรอบระยะเวลาเงินสด

`NWC = สินทรัพย์หมุนเวียน − หนี้สินหมุนเวียน`

**รอบระยะเวลาเงินสด (Cash Conversion Cycle, CCC)** ประกอบด้วย 3 องค์ประกอบ:
- `DIO (Days Inventory Outstanding) = 365 × สินค้าคงเหลือเฉลี่ย ÷ COGS`
- `DSO (Days Sales Outstanding) = 365 × ลูกหนี้การค้าเฉลี่ย ÷ ยอดขายเชื่อ`
- `DPO (Days Payable Outstanding) = 365 × เจ้าหนี้การค้าเฉลี่ย ÷ ยอดซื้อเชื่อ`
- `CCC = DIO + DSO − DPO`
- `Operating Cycle = DIO + DSO` (ไม่หัก DPO — วัดเฉพาะระยะเวลาจากซื้อสินค้าถึงเก็บเงินได้ ไม่รวมประโยชน์จากเครดิตผู้ขาย)

### 6.2 EOQ — ปริมาณการสั่งซื้อที่ประหยัดที่สุด (Economic Order Quantity)

`EOQ = √(2DS ÷ H)`
โดยที่ D = ความต้องการใช้สินค้าต่อปี, S = ต้นทุนการสั่งซื้อต่อครั้ง, H = ต้นทุนการเก็บรักษาต่อหน่วยต่อปี

**ตัวอย่าง:** กิจการต้องการวัตถุดิบ 40,000 หน่วยต่อปี ต้นทุนสั่งซื้อ 500 บาท/ครั้ง ต้นทุนเก็บรักษา 4 บาท/หน่วย/ปี
`EOQ = √(2×40,000×500 ÷ 4) = √(40,000,000÷4) = √10,000,000 ≈ 3,162 หน่วย/ครั้ง`

### 6.3 จุดที่ข้อสอบชอบออก / กับดัก

- **CCC ติดลบได้และถือว่าดี** — กิจการค้าปลีกที่ขายเงินสดแต่รับเครดิตนาน (DPO สูง) อาจมี CCC ติดลบ แปลว่าใช้เงินของซัพพลายเออร์หมุนธุรกิจโดยไม่ต้องใช้เงินตนเอง
- **Operating Cycle ≠ Cash Conversion Cycle** — สับสนกันบ่อย ต้องแยกว่า Operating Cycle ไม่หัก DPO
- **นโยบายเงินทุนหมุนเวียนเชิงรุก (Aggressive) vs เชิงระมัดระวัง (Conservative):** นโยบายเชิงรุกถือสินทรัพย์หมุนเวียนน้อย ใช้หนี้สินระยะสั้นเป็นแหล่งเงินทุนมาก (ต้นทุนต่ำแต่เสี่ยงสภาพคล่องสูง) ส่วนเชิงระมัดระวังถือสินทรัพย์หมุนเวียนมาก ใช้แหล่งเงินทุนระยะยาว (ต้นทุนสูงแต่เสี่ยงต่ำ) — ข้อสอบมักให้เปรียบเทียบผลต่อ ROA/ความเสี่ยงสภาพคล่อง

## 7. ความเสี่ยงทางการเงินจากโครงสร้างต้นทุน (Operating & Financial Leverage)

*อ้างอิงบทเรียน: `degree-of-operating-leverage` (บทที่ 7), `dfl-dcl` (แนวข้อสอบ · บทที่ 7)*

### 7.1 สูตรหลัก

| ตัวชี้วัด | สูตร | วัดความอ่อนไหวของ |
|---|---|---|
| จุดคุ้มทุน (Break-Even Point, หน่วย) | `Q(BE) = ต้นทุนคงที่ ÷ (ราคาขาย − ต้นทุนผันแปรต่อหน่วย)` | — |
| DOL (Degree of Operating Leverage) | `กำไรส่วนเกิน (Contribution Margin) ÷ EBIT` | EBIT ต่อการเปลี่ยนแปลงยอดขาย |
| DFL (Degree of Financial Leverage) | `EBIT ÷ (EBIT − ดอกเบี้ยจ่าย)` | EPS ต่อการเปลี่ยนแปลง EBIT |
| DCL (Degree of Combined Leverage) | `DOL × DFL` | EPS ต่อการเปลี่ยนแปลงยอดขายโดยตรง |

โดย กำไรส่วนเกิน (Contribution Margin) = ยอดขาย − ต้นทุนผันแปร และ EBIT = กำไรส่วนเกิน − ต้นทุนคงที่

### 7.2 ตัวอย่างซับซ้อน (ครบวงจร DOL→DFL→DCL พร้อมพยากรณ์ผล)

กิจการ: ยอดขาย 900,000 บาท ต้นทุนผันแปร 540,000 บาท ต้นทุนคงที่ 180,000 บาท ดอกเบี้ยจ่าย 60,000 บาท
- กำไรส่วนเกิน = 900,000−540,000 = 360,000
- EBIT = 360,000−180,000 = 180,000
- DOL = 360,000÷180,000 = **2.0 เท่า**
- DFL = 180,000÷(180,000−60,000) = 180,000÷120,000 = **1.5 เท่า**
- DCL = 2.0×1.5 = **3.0 เท่า**
- **การพยากรณ์:** หากยอดขายปีหน้าเพิ่มขึ้น 10% → EPS จะเปลี่ยนแปลงประมาณ DCL×10% = **30%** (ในทิศทางเดียวกัน)

### 7.3 จุดที่ข้อสอบชอบออก / กับดัก

- **สับสนตัวหารของ DOL** — DOL หารด้วย EBIT ไม่ใช่ยอดขาย และตัวตั้งคือ "กำไรส่วนเกิน (Contribution Margin)" ไม่ใช่กำไรสุทธิ
- **DFL ใช้ EBIT ลบดอกเบี้ยจ่ายเป็นตัวหาร** ไม่ใช่ EBT ลบภาษี — จุดสำคัญคือ DFL วัดผลกระทบจาก "ต้นทุนทางการเงินคงที่" (ดอกเบี้ย) เท่านั้น ภาษีไม่กระทบสัดส่วน DFL เพราะภาษีเป็นสัดส่วนคงที่ที่หักออกทั้งเศษและส่วนเท่ากัน
- **DOL/DFL/DCL สูง ไม่ได้แปลว่าแย่เสมอ** — เป็นดาบสองคม: หากยอดขายเติบโต กำไรจะโตเร็วกว่าปกติหลายเท่า แต่หากยอดขายตก กำไรก็ตกแรงกว่าปกติเช่นกัน จึงสะท้อน "ความเสี่ยง" ไม่ใช่ "คุณภาพ" ของธุรกิจ

## 8. ความเสี่ยงจากอัตราแลกเปลี่ยน (Foreign Exchange Risk)

*อ้างอิงบทเรียน: `fx-forward-hedge` (แนวข้อสอบ · บทที่ 11)*

### 8.1 เครื่องมือป้องกันความเสี่ยงหลัก

| เครื่องมือ | หลักการ |
|---|---|
| Forward Contract | ล็อกอัตราแลกเปลี่ยนล่วงหน้ากับธนาคาร รู้จำนวนเงินบาทที่แน่นอน (`มูลค่า Hedged = จำนวนเงินตราต่างประเทศ × Forward Rate`) |
| Money Market Hedge | กู้ยืม/ฝากเงินสกุลต่างประเทศวันนี้เพื่อชดเชยกระแสเงินสดในอนาคต แล้วแปลงเป็นสกุลบ้านที่อัตราสปอตปัจจุบัน |
| Options (สิทธิเลือก) | จ่ายค่าพรีเมียมเพื่อซื้อสิทธิ (ไม่ใช่ภาระผูกพัน) ในการซื้อ/ขายเงินตราต่างประเทศที่อัตราที่กำหนด — ยังได้ประโยชน์หากอัตราสปอตเคลื่อนไหวดีกว่า |

### 8.2 ทฤษฎีความเสมอภาคของอัตราดอกเบี้ย (Interest Rate Parity, IRP)

ใช้อธิบายว่า Forward Rate ควรเป็นเท่าใดตามหลักทฤษฎี (ป้องกันโอกาส Arbitrage):
`Forward Rate = Spot Rate × (1 + อัตราดอกเบี้ยสกุลบ้าน) ÷ (1 + อัตราดอกเบี้ยสกุลต่างประเทศ)`

ตัวอย่าง: Spot = 35.00 บาท/USD อัตราดอกเบี้ยไทย 3% ต่อปี อัตราดอกเบี้ยสหรัฐ 5% ต่อปี (ระยะเวลา 1 ปี)
`Forward = 35.00 × (1.03÷1.05) = 35.00×0.98095 ≈ 34.33 บาท/USD`
(สกุลเงินที่มีอัตราดอกเบี้ยสูงกว่า (USD) จะมีค่าอ่อนลงในตลาด Forward เทียบกับสกุลที่ดอกเบี้ยต่ำกว่า (บาท) — เรียกว่า "ซื้อขายที่ส่วนลด/Forward Discount")

### 8.3 จุดที่ข้อสอบชอบออก / กับดัก

- **ผู้ส่งออก (จะได้รับเงินตราต่างประเทศ) vs ผู้นำเข้า (จะต้องจ่ายเงินตราต่างประเทศ)** ต้องแยกทิศทางความเสี่ยงให้ถูก — ผู้ส่งออกกลัวเงินสกุลต่างประเทศ**อ่อนค่า**ลง (Forward ที่ทำไว้คือขาย USD ล่วงหน้า) ผู้นำเข้ากลัวเงินสกุลต่างประเทศ**แข็งค่า**ขึ้น (Forward ที่ทำไว้คือซื้อ USD ล่วงหน้า)
- **ต้นทุนแฝงของ Forward Contract** คือการเสียโอกาส (Opportunity Cost) หากอัตราสปอตจริงเคลื่อนไหวไปในทิศทางที่ดีกว่าอัตรา Forward ที่ล็อกไว้ — Forward ไม่ใช่ "กำไรฟรี" แต่เป็นการแลกความแน่นอนกับโอกาสได้ผลตอบแทนที่ดีกว่า

## 9. กระแสเงินสดอิสระและการประเมินมูลค่ากิจการ (FCFF & Firm Valuation)

*อ้างอิงบทเรียน: `fcff` (แนวข้อสอบ · บทที่ 12)*

### 9.1 สูตรหลัก

`FCFF = EBIT×(1-T) + ค่าเสื่อมราคา − CapEx − ΔNWC`

โดยที่ EBIT×(1-T) คือ NOPAT (กำไรจากการดำเนินงานหลังภาษี), CapEx คือรายจ่ายลงทุนในสินทรัพย์ถาวร, ΔNWC คือเงินทุนหมุนเวียนเพิ่มเติมที่ต้องใช้รองรับการเติบโต

**กระแสเงินสดอิสระของผู้ถือหุ้น (Free Cash Flow to Equity, FCFE):**
`FCFE = FCFF − ดอกเบี้ยจ่าย×(1-T) + เงินกู้ยืมสุทธิเพิ่มขึ้น (Net Borrowing)`

### 9.2 การประเมินมูลค่ากิจการด้วย FCFF (Firm Valuation)

เมื่อกิจการเติบโตคงที่ที่ g และมี FCFF ปีถัดไป (FCFF1):
`มูลค่ากิจการ (Enterprise Value) = FCFF1 ÷ (WACC − g)`
`มูลค่าส่วนของผู้ถือหุ้น = มูลค่ากิจการ − มูลค่าหนี้สินสุทธิ (Net Debt)`

**ตัวอย่างซับซ้อน:** EBIT 600,000 บาท อัตราภาษี 20% ค่าเสื่อมราคา 90,000 บาท CapEx 150,000 บาท ΔNWC เพิ่มขึ้น 40,000 บาท WACC = 11% อัตราเติบโตคงที่ g = 4% หนี้สินสุทธิของกิจการ 1,200,000 บาท
- NOPAT = 600,000×(1-0.20) = 480,000
- FCFF = 480,000+90,000−150,000−40,000 = **380,000**
- มูลค่ากิจการ = 380,000÷(0.11−0.04) = 380,000÷0.07 ≈ **5,428,571 บาท**
- มูลค่าส่วนของผู้ถือหุ้น = 5,428,571−1,200,000 ≈ **4,228,571 บาท**

### 9.3 จุดที่ข้อสอบชอบออก / กับดัก

- **FCFF ≠ OCF** — FCFF หัก CapEx และ ΔNWC เพิ่มเติมจาก OCF เพื่อให้เหลือกระแสเงินสดที่ "เป็นอิสระ" จริง ๆ ที่นำไปจ่ายให้ผู้ให้ทุนทุกฝ่ายได้ ข้อสอบชอบให้คำนวณ OCF ก่อนแล้วถามต่อว่า FCFF เท่าใด เพื่อทดสอบว่าเข้าใจความแตกต่าง
- **FCFF ใช้ EBIT×(1-T) ไม่ใช่กำไรสุทธิ (NI)** เพราะ FCFF เป็นกระแสเงินสดก่อนหักดอกเบี้ย (Unlevered) สะท้อนกระแสเงินสดที่เป็นของผู้ให้ทุนทุกฝ่ายรวมกัน (ไม่ใช่ของผู้ถือหุ้นอย่างเดียวแบบ FCFE)
- **สูตร Perpetuity Growth (WACC−g)** ใช้ได้เฉพาะเมื่อกิจการเติบโตแบบคงที่และยั่งยืน (g < WACC เสมอ) หากกิจการอยู่ในช่วงเติบโตสูงต้องใช้แบบ Two-Stage เหมือนหุ้นสามัญ (คิดลด FCFF แต่ละปีแยกในช่วงเติบโตสูง แล้วบวกมูลค่าปลายช่วง)

        │                                          │

        │                                          │
